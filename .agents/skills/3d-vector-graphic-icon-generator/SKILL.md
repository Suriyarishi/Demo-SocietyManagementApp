# 3D Vector Graphic Icon Generator

## Purpose

Create clean, reusable 3D vector-style icons and graphic elements for
modern UI/UX products. Assets should feel friendly, polished, readable,
and visually consistent.

## When to use

Use this skill when the user asks to: - Create 3D vector icons or
graphic elements. - Generate a matching set of app or dashboard icons. -
Create an isolated 3D illustration for an empty state, feature card,
onboarding screen, or success state. - Adapt an existing icon concept
into a 3D vector-style visual.

## Design principles

1.  **One clear subject:** Keep each icon focused on one object or idea.
2.  **Consistent visual language:** Match perspective, lighting
    direction, material, shadow softness, and detail level across a set.
3.  **Simple silhouettes:** Keep icons recognizable at small sizes.
4.  **UI-friendly composition:** Avoid clutter and unnecessary
    decoration.
5.  **Balanced depth:** Use subtle extrusion, rounded bevels, soft
    highlights, and believable contact shadows.
6.  **Accessible contrast:** Separate the subject clearly from the
    background.
7.  **Reusable output:** Prefer isolated assets that can be placed on
    different UI backgrounds.

## Default visual style

-   Style: polished 3D vector illustration, not photorealistic.
-   Geometry: rounded, smooth, simplified forms.
-   Perspective: consistent three-quarter view unless specified
    otherwise.
-   Lighting: soft studio lighting from the upper-left.
-   Materials: matte or satin finish with controlled highlights.
-   Shadows: soft, subtle grounding shadow.
-   Background: transparent when supported; otherwise plain white or a
    specified solid color.
-   Composition: centered subject with comfortable padding.
-   Palette: use supplied brand colors; otherwise choose a restrained,
    harmonious palette.

## Workflow

1.  Identify the icon's meaning, intended UI placement, and target
    audience.
2.  Extract supplied brand colors, reference style, aspect ratio, and
    background requirements.
3.  Define a simple object metaphor that communicates the meaning
    immediately.
4.  Generate the icon with a consistent three-quarter perspective and
    lighting.
5.  Check silhouette clarity, visual balance, edge quality, and
    small-size legibility.
6.  For icon sets, keep scale, camera angle, lighting, shadows, and
    materials consistent.
7.  Revise ambiguous or overly detailed elements.

## Output requirements

-   Create one separate asset per requested icon unless a sheet is
    requested.
-   Use a square composition by default.
-   Keep the subject fully inside the canvas.
-   Do not add labels, captions, watermarks, borders, or UI mockups
    unless requested.
-   Use transparent PNG when transparency is requested and supported.
-   If editable vector source is requested, provide SVG or another
    genuinely editable vector format. Do not describe a raster PNG as
    editable vector artwork.
-   Follow supplied brand colors and dimensions exactly when provided.

## Prompt template

Create a polished 3D vector-style icon representing **\[ICON CONCEPT\]**
for **\[PRODUCT / UI CONTEXT\]**. Use simplified rounded geometry, a
consistent three-quarter perspective, soft upper-left studio lighting,
subtle bevels, a clean matte/satin material, and a soft grounding
shadow. Use **\[COLOR PALETTE\]**. Center one clear subject with
generous padding. Background: **\[TRANSPARENT / SOLID COLOR\]**. No
text, labels, watermark, border, or extra objects. Keep the silhouette
immediately recognizable at small UI sizes.

## Quality checklist

-   [ ] The icon communicates one clear idea.
-   [ ] The silhouette is recognizable at small sizes.
-   [ ] Perspective and lighting match the rest of the set.
-   [ ] The subject has enough contrast against the background.
-   [ ] No unwanted text, watermark, or clutter appears.
-   [ ] The requested background and output format are respected.
-   [ ] Raster PNG is not falsely described as editable vector artwork.
